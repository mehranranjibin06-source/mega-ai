🔑 گرفتن کلید هوش مصنوعی — ۲ دقیقه، بدون کارت بانکی

هر کدام را که راحت‌تر بود انتخاب کن. همه بدون کارت بانکی‌اند. پایین‌تر: Groq (۴۰۰ میلیارد/۱ تریلیون) و OpenRouter (۶۷۱ میلیارد) — بالاترین هوش‌ها با فقط یک ایمیل.
۰
سریع‌ترین راه: بدون هیچ کلیدی! 🌐 Pollinations

یک سرویس عمومی رایگان که نه ثبت‌نام می‌خواهد و نه کلید. برنامه از همین حالا می‌تواند با آن جواب بدهد.

در 🧠 مغز کارت Pollinations را بزن «✅ تست کن» — اگر سبز شد، تمام. (اگر شبکه‌ات بسته باشد، بقیهٔ گزینه‌های پایین را ببین.)

🎁
لیست کلیدهای رایگان (تست‌شده — شهریور ۱۴۰۵)

🇮🇷 ایرانی — بدون فیلترشکن:

• 1xAi — ۳۸+ مدل (GPT، Claude، Gemini، DeepSeek)، سهمیهٔ ماهانهٔ رایگان، کلید تومانی: 1xai.ir

• SinoxAPI — ۲۲ مدل، شروع رایگان: sinoxapi.com

• WinkAPI — مدل‌های GPT/Claude/Gemini: winkapi.net

• GapGPT — پلن رایگان تا ۵٬۰۰۰ درخواست در ماه: gapgpt.app

• Jarvis — یک کلید برای GPT/Claude/Gemini/Grok: jarvis.you

• AvalAI — اعتبار هدیه برای کاربر تازه: avalai.ir

🌍 جهانی — رایگان، بدون کارت بانکی (VPN لازم است):

• Pollinations — بدون هیچ کلیدی کار می‌کند (همین حالا فعال است)

• Groq — console.groq.com/keys (سریع‌ترین، gpt-oss-120b)

• OpenRouter — openrouter.ai/keys (۵۵۰ میلیارد پارامتر رایگان)

• Google Gemini — aistudio.google.com/apikey (رایگان و سخاوتمند)

• Mistral — console.mistral.ai (ماهانه ۱۰ دلار اعتبار رایگان)

• LLM7 — dash.llm7.io (کلید رایگان با حساب گیت‌هاب)

• NVIDIA — build.nvidia.com (۸۲ مدل، بدون کارت)

• Z.ai (GLM) — z.ai (مدل‌های Flash رایگان)

هر کلیدی را گرفتی، در تب 🧠 مغز بچسبان؛ خودش تشخیص می‌دهد کدام سرویس است و تست می‌کند.

🧠
Groq — رایگان، بدون کارت بانکی، و بسیار سریع (کلید فقط با ایمیل)

سرویس رایگان Groq مدل‌های عظیم دارد: GPT-OSS 120 میلیارد (قوی‌ترین مدل رایگانش) و compound که خودش ابزار و وب‌گردی دارد. خیلی هم سریع است. کلیدش با ایمیل داده می‌شود و هیچ کارت بانکی نمی‌خواهد.

⚠️ مهم: سایتش از ایران بسته است → فیلترشکن روشن باشد (فقط برای گرفتن کلید؛ بعدش کلید می‌ماند).

بازکردن صفحهٔ کلیدهای Groq
۱
با فیلترشکن، سایت Groq را باز کن

آدرس: console.groq.com/keys — بالا-راست دکمهٔ Sign in است.

روش ورود: Continue with Google (اگر جیمیل داری، ساده‌ترین است) یا Continue with Email. ایمیل جیمیل خودت را بزن؛ وصلی، صفحه‌اش باز می‌شود.

۲
دکمهٔ ساخت کلید

در صفحهٔ API Keys دکمهٔ آبی Create API Key را بزن.

یک پنجره باز می‌شود: در کادر Display Name بنویس mega → بعد Submit.

۳
کلید را کپی کن

کلیدی نشانت می‌دهد که با gsk_ شروع می‌شود → دکمهٔ Copy کنارش را بزن.

⚠️ این کلید فقط یک بار کامل نشان داده می‌شود؛ همین حالا کپی کن.

۴
در برنامه بچسبان — مغزت بزرگ می‌شود

برگرد به برنامه → تب 🧠 مغز → در کادر Groq کلید را پیست کن → دکمهٔ ذخیره و تست.

اگر پیام ✅ موفق دیدی، مغزت شده ۱ تریلیون پارامتر یا ۴۰۰ میلیارد (خودش قوی‌ترین را برمی‌دارد).

رفتن به تب مغز
!
اگر تست گفت «ناموفق» (چون سرور ایران است)

سرور تو در ایران است و Groq درخواست‌های ایرانی را رد می‌کند. راهش ساده است:

در همان تب 🔑 کلیدها یک کادر پروکسی هست. آدرس پروکسی فیلترشکن خودت را بگذار، مثلاً http://127.0.0.1:10809 (یا پورتی که برنامهٔ فیلترشکن روی وی‌پی‌اس نشان می‌دهد) → ذخیره.

بعد دوباره در تب 🧠 مغز دکمهٔ تست را بزن. اگر «موفق» شد، تمام است.

➕
گزینهٔ مکمل: OpenRouter — ۶۷۱ میلیارد پارامتر (هم رایگان، هم فقط ایمیل)

۱) با فیلترشکن برو به openrouter.ai/keys → Sign in → Continue with Google.

۲) دکمهٔ Create Key → در Name بنویس mega → Create.

۳) کلیدی که با sk-or- شروع می‌شود را کپی کن → در تب 🧠 مغز، کارت OpenRouter، پیست و ذخیره و تست.

مدل رایگانش: nemotron-3-ultra-550b — ۵۵۰ میلیارد پارامتر با ۱ میلیون توکن حافظه، و قیمتش ۰ دلار (از فهرست لحظه‌ای OpenRouter چک شد). (نکتهٔ پروکسی اینجا هم لازم است.)

★
راه رایگان و بدون کارت بانکی: Cloudflare (پیشنهاد ما)

۱) ثبت‌نام با ایمیل: dash.cloudflare.com/sign-up

۲) صفحهٔ توکن‌ها → دکمه Create Token → قالب Workers AI → Continue → Create Token

۳) توکن را کپی کن و در جعبهٔ کلیدِ همین برنامه بچسبان — خودش ذخیره و تست می‌شود.

روزانه ۱۰٬۰۰۰ واحد رایگان با مدل‌های Llama 70B و GPT-OSS — بدون کارت، بدون پول.

۱
سایت AvalAI را باز کن

از داخل ایران کار می‌کند — نیازی به فیلترشکن نیست. ثبت‌نام رایگان است و به کاربران جدید اعتبار هدیه می‌دهند.

رفتن به avalai.ir
۲
ثبت‌نام با شماره موبایل

شماره‌ات را بزن → کد پیامک‌شده را وارد کن. تمام. (اگر خواست، ایمیل هم بزن.)

۳
کلید بساز

در پنل AvalAI برو به بخش API Keys → دکمه Create / ساخت کلید جدید → کلید ساخته می‌شود.

کلیدی که با aa- یا sk- شروع می‌شود را کپی کن (دکمهٔ کپی کنارش).

۴
کلید را به برنامه بده

برگرد به برنامه → بخش 🔑 کلیدها → کلید را پیست کن → ذخیره.

اگر پیام ✅ دیدی، هوش وصل شد. همین!
