راه رایگان و بدون کارت بانکی: Cloudflare (پیشنهاد ما)

۱) ثبت‌نام با ایمیل: dash.cloudflare.com/sign-up

۲) صفحهٔ توکن‌ها → دکمه Create Token → قالب Workers AI → Continue → Create Token

۳) توکن را کپی کن و در جعبهٔ کلیدِ همین برنامه بچسبان — خودش ذخیره و تست می‌شود.

روزانه ۱۰٬۰۰۰ واحد رایگان با مدل‌های Llama 70B و GPT-OSS — بدون کارت، بدون پول.

۱
سایت AvalAI را باز کن

از داخل ایران کار می‌کند — نیازی به فیلترشکن نیست. ثبت‌نام رایگان است و به کاربران جدید اعتبار هدیه می‌دهند.

رفتن به avalai.ir
۲
ثبت‌نام با شماره موبایل

شماره‌ات را بزن → کد پیامک‌شده را وارد کن. تمام. (اگر خواست، ایمیل هم بزن.)

۳
کلید بساز

در پنل AvalAI برو به بخش API Keys → دکمه Create / ساخت کلید جدید → کلید ساخته می‌شود.

کلیدی که با aa- یا sk- شروع می‌شود را کپی کن (دکمهٔ کپی کنارش).

۴
کلید را به برنامه بده

برگرد به برنامه → بخش 🔑 کلیدها → کلید را پیست کن → ذخیره.

اگر پیام ✅ دیدی، هوش وصل شد. همین!
