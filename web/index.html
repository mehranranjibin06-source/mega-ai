⚡ سرعت پاسخ
اگر جواب‌ها دیر می‌آید، «سریع» را بزن: مدل سبک‌تر + گام‌های کمتر. برای کارهای سنگین (کد، تحلیل) «دقیق» بهتر است.

🟢 Groq — رایگان، بدون کارت، و بسیار سریع

GPT-OSS 120 میلیارد (قوی‌ترین مدل رایگانش — با کلید واقعی تست شد ✅)
compound: سیستم ترکیبی Groq که خودش ابزار و وب‌گردی دارد
سرعتش حدود ۱۰ برابر کلادفلر است (۲۴۵ میلی‌ثانیه در تست). فقط ایمیل لازم است.
کلید با gsk_ شروع می‌شود

🔵 OpenRouter — مدل‌های ۲۰۰ تا ۷۰۰ میلیاردی رایگان

۵۵۰ میلیارد پارامتر — nemotron-3-ultra-550b رایگان (۰ دلار، ۱ میلیون توکن حافظه) ✅
۱۲۰ میلیارد — nemotron-3-super رایگان · و مدل‌های رایگان سبک‌تر
بدون کارت بانکی، فقط ایمیل. (از ایران باید VPN روشن باشد)
کلید با sk-or- شروع می‌شود

📊 راهنمای اندازهٔ مدل‌ها

• 🟢 Cloudflare (وصل است) → بزرگ‌ترینش ۱۲۰ میلیارد — رایگان روزانه، بدون هیچ کارت.
• 🟢 Groq → ۱۲۰ میلیارد ولی فوق‌سریع — رایگان با ایمیل.
(مدل‌های ۴۰۰ میلیاردی/۱ تریلیونی Groq بازنشسته شدند؛ بزرگ‌ترین رایگانش همین ۱۲۰ است)
• 🟢 OpenRouter → ۵۵۰ میلیارد (nemotron-3-ultra، رایگان و ۰ دلار) — با ایمیل.
• 🔒 اینترنت تو از ایران بسته است؛ اگر کلید نگیرد، در 🔑 کلیدها آدرس پروکسی (مثل http://127.0.0.1:10809) را هم وارد کن.

🧪 تست کامل — «همه بخش‌ها خوب کار می‌کنند؟»

این تست روی همین سرور تو اجرا می‌شود (نه از اینترنت بیرون)، پس هرچه نشان می‌دهد دقیقاً وضعیت خودت است: کدام سرویس هوش کلیدش سالم است، کدام سایت‌ها از شبکهٔ تو باز می‌شوند، و کدام بخش برنامه کار می‌کند.

📨 دستیار تلگرام

توکن ربات را از @BotFather بگیر و اینجا بگذار. بعد از فعال شدن، هر پیام/صدا/فایلی که به ربات بدهی توسط کارگزار اجرا می‌شود و خروجی (متن، ویدیو، تصویر، فایل) برایت برمی‌گردد.

💡 چه کارهایی از تلگرام می‌شود

  • «یک تبلیغ برای محصولم بساز» → ویدیو برایت می‌فرستد
  • 🎙 پیام صوتی بفرست → متن و اجرا
  • 📎 فایل داده بفرست → تحلیل + نمودار
  • /say متن → پاسخ صوتی
  • /status وضعیت، /new نشست تازه

🔑 کلیدهای API

هر پرووایدری کلید داشته باشد خودکار وارد سیستم می‌شود. ساده‌ترین راه: یک کلید OpenRouter (با یک کلید به GPT، Claude، Gemini، Grok، DeepSeek، Qwen و Llama دسترسی داری).
