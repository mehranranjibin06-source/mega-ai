📨 دستیار تلگرام

توکن ربات را از @BotFather بگیر و اینجا بگذار. بعد از فعال شدن، هر پیام/صدا/فایلی که به ربات بدهی توسط کارگزار اجرا می‌شود و خروجی (متن، ویدیو، تصویر، فایل) برایت برمی‌گردد.

💡 چه کارهایی از تلگرام می‌شود

  • «یک تبلیغ برای محصولم بساز» → ویدیو برایت می‌فرستد
  • 🎙 پیام صوتی بفرست → متن و اجرا
  • 📎 فایل داده بفرست → تحلیل + نمودار
  • /say متن → پاسخ صوتی
  • /status وضعیت، /new نشست تازه

🔑 کلیدهای API

هر پرووایدری کلید داشته باشد خودکار وارد سیستم می‌شود. ساده‌ترین راه: یک کلید OpenRouter (با یک کلید به GPT، Claude، Gemini، Grok، DeepSeek، Qwen و Llama دسترسی داری).
