# ۲) دستیار صوتی (جارویس)

> روش پیشنهادی: 🛠 انجامش بده

```
یک دستیار صوتی شخصی بساز (مثل جارویس) که روی همین کامپیوتر اجرا شود:

- گفتار → متن: از میکروفون سیستم یا فایل صوتی (whisper یا سرویس موجود در سیستم)
- مغز: کارگزار همین پروژه (چند مدل + ابزارها) با حافظه‌ی گفت‌وگو در SQLite
- متن → گفتار: صدای فارسی طبیعی، با انتخاب چند صدا
- دستورهای واقعی که باید اجرا کند: باز کردن برنامه، جست‌وجوی وب، یادآوری زمان‌دار،
  نوشتن/خواندن فایل، انجام محاسبه، ساخت تصویر یا ویدیوی کوتاه
- یک رابط گرافیکی ساده (Tkinter یا صفحه‌ی وب محلی) با دکمه‌ی «حرف بزن»، نمایش متن،
  و حباب گفت‌وگو + کلید میان‌بر سراسری (مثلاً Ctrl+Space) برای بیدار شدن
- فایل اجرای خودکار در ویندوز/مک و README فارسی

خروجی: کد کامل + اجرای واقعی + یک نمونه‌ی ضبط‌شده از پاسخ صوتی Persian در همین نشست
```
