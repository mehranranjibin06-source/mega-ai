# ۶) جمع‌آور داده از وب

> روش پیشنهادی: 🛠 انجامش بده

```
یک سامانه‌ی جمع‌آوری داده بساز:

- هدف نمونه: استخراج قیمت و مشخصات از یک سایت فروشگاهی (سایت هدف را از من بپرس، یا با یک سایت نمونه شروع کن)
- معماری: صف کارها، درخواست با تأخیر محترمانه، مقاوم به خطا، ذخیره در SQLite، جلوگیری از تکرار
- استخراج: HTML با BeautifulSoup و برای صفحات پویا Playwright/Selenium (اگر لازم بود نصب کن)
- خروجی: CSV/Excel + گزارش تغییرات قیمت + هشدار برای افت‌های بیشتر از ۵٪
- زمان‌بندی: اسکریپت cron در لینوکس/مک و Task Scheduler در ویندوز + اجرای دستی
- رعایت اخلاق و قانون: robots.txt، نرخ درخواست پایین، فقط داده‌ی عمومی

خروجی: کد + اجرای واقعی روی حداقل ۲۰ آیتم + فایل داده + راهنمای زمان‌بندی
```
