# 🚀 پروژه‌های آماده (Inception)

این پوشه، «پرامپت‌های بزرگی» است که کارگزار MEGA-AI را وادار می‌کند پروژه‌های واقعی و سطح‌بالا بسازد.
هر فایل یک پروژه است: کافی است متنش را در پنل بچسبانی و دکمهٔ **🛠 انجامش بده** را بزنی
(برای بخش‌های طراحی/استراتژی، **🧠 جواب دقیق** بهتر جواب می‌دهد).

قاعدهٔ طلایی: هرچه خواسته دقیق‌تر، خروجی حرفه‌ای‌تر. اسم فایل‌ها و تکنولوژی را همان‌جا که می‌دانی بنویس.

| فایل | چه چیزی ساخته می‌شود |
|---|---|
| `01-saas-fullstack.md` | یک SaaS کامل: فرانت + API + دیتابیس + ورود کاربر + پرداخت + دیپلوی |
| `02-jarvis-assistant.md` | دستیار صوتی شخصی (گوش می‌دهد، حرف می‌زند، کار انجام می‌دهد) |
| `03-video-factory.md` | خط تولید ویدیوی تبلیغاتی: عکس/متن → ویدیو با صداگذاری و زیرنویس |
| `04-data-analyst.md` | داشبورد تحلیل داده با گزارش خودکار فارسی و نمودار |
| `05-mobile-app.md` | اپ موبایل (Flutter) قابل نصب + بک‌اند |
| `06-scraper-platform.md` | جمع‌آور داده از وب + ذخیره‌سازی + گزارش + زمان‌بندی |
| `07-telegram-bot-shop.md` | ربات تلگرام فروشگاهی با سبد خرید و سفارش |
| `08-portfolio-site.md` | سایت شخصی/شرکتی سریع (PWA) با فرم تماس |

نمونهٔ کوچک در همین پوشه: `example/` (یک پروژهٔ واقعی که با همین سیستم ساخته شد).
