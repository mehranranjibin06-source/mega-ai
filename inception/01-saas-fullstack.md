# ۱) SaaS کامل

> روش پیشنهادی: 🛠 انجامش بده

```
یک سرویس SaaS کامل بساز با این مشخصات:

- هدف: پنل مدیریت سفارش برای فروشگاه‌های کوچک (چند-کاربره)
- بک‌اند: FastAPI + SQLite (بعداً قابل تبدیل به Postgres) + JWT برای ورود + نقش ادمین/کاربر
- مدل‌های داده: کاربر، کسب‌وکار، مشتری، محصول، سفارش، آیتم سفارش، پرداخت — با مهاجرت و داده‌ی نمونه
- API: CRUD کامل + فیلتر/جست‌وجو/صفحه‌بندی + خروجی CSV و Excel + مستندات OpenAPI
- فرانت: یک صفحه‌ی HTML فارسی راست‌چین و زیبا (بدون وابستگی اینترنتی) با ورود، داشبورد، جدول سفارش‌ها،
  فیلتر، نمودار فروش هفتگی، افزودن/ویرایش سفارش و چاپ فاکتور
- تست‌ها: pytest برای مسیرهای اصلی (ورود، ساخت سفارش، جمع فروش) — همه باید سبز شوند
- اجرا: فایل README با دستور نصب و اجرا + فایل requirements.txt + اجرای واقعی سرور و تست دود (smoke test)

خروجی نهایی که باید تحویل بدهی:
1) کد کامل پروژه در پوشه‌ی همین نشست  2) نتیجه‌ی واقعی اجرای تست‌ها  3) آدرس محلی اجرای سرور  4) راهنمای گام‌به‌گام راه‌اندازی
```
