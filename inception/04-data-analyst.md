# ۴) داشبورد تحلیل داده

> روش پیشنهادی: 🛠 انجامش بده

```
یک داشبورد تحلیل داده بساز که فایل خام (CSV/Excel) را بگیرد و گزارش فارسی تحویل بدهد:

- پاک‌سازی: تشخیص خودکار جداکننده، کدگذاری، ستون تاریخ، مقادیر گم‌شده، سطر تکراری
- آمار: خلاصه‌ی هر ستون، پرتکرارها، همبستگی‌ها، شاخص‌های کلیدی کسب‌وکار (فروش، رشد، میانگین سبد)
- نمودارها: روند زمانی، پرتکرارها، توزیع، Pareto، مقایسه‌ی ماه‌به‌ماه — همه با فونت فارسی
- خروجی: گزارش HTML تک‌فایلی فارسی راست‌چین (نمودارها جاسازی‌شده) + فایل Excel جمع‌بندی + تصاویر نمودار
- یک صفحه‌ی وب محلی که کاربر فایل را داخلش بیندازد و گزارش را همان‌جا ببیند
- در پایان: سه نکته‌ی مهم و سه پیشنهاد عملی بر اساس داده‌ی واقعی (نه حرف کلی)
```
