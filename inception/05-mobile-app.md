# ۵) اپ موبایل (فلاتر)

> روش پیشنهادی: 🛠 انجامش بده

```
یک اپ موبایل کامل با Flutter بساز:

- موضوع: مدیریت هزینه‌های شخصی با نمودار و دسته‌بندی فارسی
- صفحات: ورود ساده، لیست هزینه‌ها، افزودن هزینه، نمودار ماهانه، تنظیمات، پشتیبان‌گیری
- ذخیره‌سازی محلی (sqflite) + همگام‌سازی اختیاری با یک بک‌اند FastAPI که همین‌جا بسازی
- پشتیبانی فارسی وراست‌چین، تاریخ شمسی، واحد ریال/تومان
- کد تمیز با ساختار پوشه‌ای درست، تست ویجت، فایل README نصب
- اگر Flutter SDK در سیستم نیست: نصبش را امتحان کن، و اگر نشد پروژه‌ی کامل و قابل‌اجرا بساز
  و دقیقاً بنویس با چه دستوری روی سیستم من (ویندوز/مک) اجرا و بیلد می‌شود

خروجی: پروژه‌ی کامل + APK در صورت امکان بیلد + راهنمای فارسی
```
