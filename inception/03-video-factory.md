# ۳) خط تولید ویدیوی تبلیغاتی

> روش پیشنهادی: 🛠 انجامش بده

```
یک خط تولید ویدیوی تبلیغاتی بساز که از «عکس + متن» ویدیوی آماده‌ی انتشار بیرون بدهد:

- ورودی: یک عکس (اگر عکس بده‌ام همین عکس را تحلیل کن و به‌عنوان پس‌زمینه بگذار)، نام برند، سه مزیت، شماره تماس
- خروجی: ویدیوی ۹:۱۶ با گویندگی فارسی، زیرنویس سوخته، حرکت آرام روی عکس (Ken Burns)، موسیقی ملایم
- علاوه بر ویدیو: پوستر ۹:۱۶ و ۱:۱ و نسخه‌ی ۱۶:۹ برای سایت + فایل .srt قابل ویرایش
- سه نسخه بساز: یکی ۱۵ ثانیه‌ای (استوری)، یکی ۳۰ ثانیه‌ای (ریلز)، یکی ۶۰ ثانیه‌ای (تبلیغ کامل)
- در پایان: فهرست فایل‌ها با لینک دانلود + توضیح اینکه هر نسخه کجا استفاده می‌شود
```
