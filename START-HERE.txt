این بستهٔ کامل برنامه است: همهٔ کدها + همهٔ صفحه‌های HTML + assets (لوگو و فونت) + فایل‌های نصب.

┌──────────────────────────────────────────────┐
│  ۱) نصب (فقط یک بار)                          │
└──────────────────────────────────────────────┘
الف) اگر فایل  mega_ai_installer.bat  را داری:
    فقط دوبار کلیک کن. کل برنامه داخل خودش است، هیچ اینترنتی لازم ندارد.

ب) اگر همین فایل زیپ را داری:
    ۱. کل محتوای زیپ را در پوشهٔ  C:\Users\Administrator\mega-ai-main  بریز
    ۲. در همان پوشه، پنجرهٔ CMD باز کن و این یک خط را بزن:
          python start_vps.py
    برنامه خودش همهٔ کتابخانه‌ها را با pip نصب می‌کند
    (اول از آینهٔ ایرانی، اگر نشد از pypi.org و آینه‌های دیگر).
    بار اول ۳ تا ۷ دقیقه طول می‌کشد. دفعه‌های بعد چند ثانیه.

┌──────────────────────────────────────────────┐
│  ۲) کتابخانه‌ها و پیش‌نیازها خودکار نصب می‌شوند │
└──────────────────────────────────────────────┘
• fastapi, uvicorn, httpx  (هستهٔ برنامه)
• pillow, edge-tts         (عکس و صدا)
• pandas, numpy, matplotlib, openpyxl, pypdf, python-docx  (اکسل/نمودار/PDF)
• ffmpeg                   (برای ویدیو — خودش تلاش می‌کند نصب کند)

اگر جایی گیر کرد، همان پیام را برای دستیار بفرست. دستور دستی هم هست:
    python -m pip install -r requirements.txt

┌──────────────────────────────────────────────┐
│  ۳) روشن شدن خودکار + باز شدن پورت (توصیه)    │
└──────────────────────────────────────────────┘
یک بار روی  setup_autostart.bat  دوبار کلیک کن (باید setup_autostart.ps1 کنارش باشد).
خودش Administrator می‌گیرد و:
   • پورت‌های ۸۰۰۰ تا ۸۰۱۰ را در فایروال ویندوز باز می‌کند (تا موبایل وصل شود)
   • برنامه را «هنگام روشن شدن ویندوز» خودکار اجرا می‌کند (تسک زمان‌بندی)
   • نگهبان می‌گذارد: اگر برنامه بست، خودش دوباره بالا می‌آید
   • همین حالا برنامه را روشن می‌کند

خاموش‌کردن روشن‌شدن خودکار:   schtasks /delete /tn MehranAiShabestar /f

│  ۴) روشن کردن دستی (هر وقت خواستی)            │
└──────────────────────────────────────────────┘
