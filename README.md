# 🧠 MehranAiShabestar — کارگزار مطلق اختصاصی تو

یک سیستم **چند-هوشی + چند-کاره** که برای تو کار **می‌کند**، نه اینکه فقط جواب بدهد:
برنامه می‌نویسد و اجرا می‌کند، پکیج نصب و کتابخانه‌ها را به‌روز می‌کند، داده می‌گیرد و تحلیل می‌کند،
سایت/API/ربات/PWA/اپ موبایل می‌سازد، **ویدیو و تبلیغ** می‌سازد، صداگذاری و زیرنویس می‌کند،
و از تلگرام هم فرمان می‌گیرد.

> روی سرور خودت اجرا می‌شود؛ هیچ بخشی از داده‌ات به جای دیگری نمی‌رود جز خود مدل‌هایی که انتخاب می‌کنی.

## ۱) راه‌اندازی — از ایران، بدون محدودیت، یک‌دستوری

سه راه داری؛ هر کدام راحت‌تر بود:

| راه | دستور | برای چه کسی |
|---|---|---|
| 🐧 مک/لینوکس | `./start.sh` | ساده‌ترین راه — خودش پکیج‌ها را نصب می‌کند و مرورگر را باز می‌کند |
| 🪟 ویندوز | روی `start.bat` دوبار کلیک کن | همان کار، برای ویندوز |
| 💻 نصب روی لپ‌تاپ خودت | `python run_local.py` | محیط مجازی خودش را می‌سازد، پورت آزاد برمی‌دارد، مرورگر را باز می‌کند |
| 📱 از گوشی هم | `python run_local.py --lan` | از هر دستگاهی روی همان وای‌فای در دسترس است |
| 🐳 داکر | `docker compose up --build` | اگر داکر داری؛ ffmpeg و فونت‌ها از قبل داخلش هست |
| ⚙️ دستی | `pip install -r requirements.txt` بعد `python3 server.py` | اگر خودت کنترل کامل می‌خواهی |

بعد از اجرا: **<http://localhost:8000>** → پنل آسان. نسخهٔ حرفه‌ای ۷-تبی هم روی **<http://localhost:8000/advanced>** است.

### پنل آسان (`/`) — ۳ گام و تمام

1. **سرویس را انتخاب کن** — گیت‌وی‌های **ایرانی** اول لیست آمده‌اند (AvalAI، GapGPT، MetisAI، WinkAPI، SinoxAPI، Jarvis) با لینک ثبت‌نام؛ هر کدام یک کلید می‌دهد و پشتش GPT و Claude و Gemini هست. اگر سرویس خودت را داری، «سفارشی» را بزن و آدرس + مدل را وارد کن (Ollama، vLLM، هر آدرس سازگار با OpenAI).
2. **کلید را بچسبان** → دکمهٔ **🔌 تست اتصال** (واقعاً وصل می‌شود و مدل‌های موجود را می‌آورد) → **💾 ذخیره**.
3. **حرف بزن** — سه دکمه‌ی اصلی:
   - ⚡ **جواب سریع**: پاسخ فوری با استریم (سبک و ارزان)
   - 🧠 **جواب دقیق**: چند مدل، نقد متقابل، داوری و سنتز
   - 🛠 **انجامش بده**: کارگزار واقعاً اجرا می‌کند و فایل تحویل می‌دهد

دکمه‌های کنارش: 🎤 میکروفون (فارسی)، 📎 فایل، 🎬 استودیو، و ⚙️ تنظیمات (پروکسی، سطح قدرت، «بررسی همه‌ی سرویس‌ها»).
اگر هیچ کلیدی نداشته باشی، **حالت نمایشی** روشن می‌ماند و باز هم می‌توانی ویدیو/پوستر واقعی بسازی و همه‌چیز را امتحان کنی.

### 📎 فایل بده → تحلیل/بساز (تازه اضافه شد)

در پنل، دکمه‌ی **📎 آپلود فایل / عکس** را بزن. هر چیزی را می‌توانی بدهی:

| چه می‌دهی | چه اتفاقی می‌افتد |
|---|---|
| 🖼 عکس | تحلیل واقعی: ابعاد، نسبت، روشنایی، کنتراست، وضوح، رنگ‌های غالب، برش پیشنهادی + (اگر کلید باشد) توصیف هوشمند با مدل بینایی |
| 🖼 عکس + «از همین عکس پوستر بساز» | پوستر واقعی ۹:۱۶ / ۱:۱ / ۱۶:۹ با برش هوشمند و متن فارسی روی عکس خودت |
| 🖼 عکس + «از این عکس تبلیغ ویدیویی بساز» | ویدیوی تبلیغی که عکس تو پس‌زمینه‌ی همه‌ی صحنه‌هاست + گویندگی + زیرنویس |
| 📊 CSV / Excel | آمار کامل هر ستون، مقادیر گم‌شده، تکراری‌ها، همبستگی‌ها، پرتکرارها + **سه نمودار فارسی** |
| 💻 کد (py/js/…) | تعداد خط و تابع، خطاهای نگارشی با شماره‌ی خط، وابستگی‌ها، تودرتویی، TODOها |
| 📄 متن / Word / PDF | تعداد کلمه، پرتکرارها، سرتیترها، زمان مطالعه، پیش‌نمایش |
| 🗜 ZIP | فهرست محتوا و پسوندهای داخل آرشیو |
| 🎧 صدا / 🎬 ویدیو | مدت، نرخ بیت، کدک‌ها، تعداد کانال |

یا فقط بنویس «**این فایل را تحلیل کن**» یا «**چه اشکالی دارد؟**» — کارگزار خودش فایل را برمی‌دارد،
باز می‌کند، اندازه می‌گیرد و گزارش می‌دهد. زیر هر فایل آپلودی سه دکمه هم هست:
**🔍 تحلیل** · **🖼 پوستر** · **🎬 تبلیغ**.

راهنمای کامل در فایل **`GITHUB.md`** است. خلاصه‌ی سه راه:

| راه | چطور | نتیجه |

| 💻 از لپ‌تاپ | `github_publish.bat` (ویندوز) یا `./github_publish.sh <آدرس-مخزن>` | یک‌دستوری همه‌چیز push می‌شود |

### 🚀 پروژه‌های آماده (`inception/`)

پوشه‌ی `inception/` هشت **پرامپت بزرگ** دارد (SaaS کامل، دستیار صوتی، خط تولید ویدیو، داشبورد داده،
اپ موبایل، جمع‌آور داده، ربات فروشگاهی، سایت PWA). در پنل، بخش «🚀 پروژه‌های آماده» را باز کن و
با یک کلیک پرامپت را در کادر بگذار و «🛠 انجامش بده» را بزن.

### 🧠 «ابرهوش» — چطور از چند هوش کمک می‌گیرد؟

در حالت **🧠 جواب دقیق** (و «عمیق») این زنجیره اجرا می‌شود:

1. **مغز راهبر** درخواست را تحلیل می‌کند و نقشه می‌سازد (نوع کار، معیار موفقیت، نیاز به پژوهش وب).
2. **شبکه‌ی دانش (تازه):** چند مدل **موازی** هرکدام یک زاویه را می‌کاوند — واقعیت‌ها، تجربه‌ی عملی،
   خطرها، راه‌حل رقیب. یافته‌ها بین همه پخش می‌شود تا هر خبره از دانش بقیه خبر داشته باشد.
3. **پنل خبرگان موازی** (تا ۸ مدل با نقش‌های متفاوت) جواب می‌دهند.
4. **نقد متقابل:** پاسخ‌ها بی‌نام می‌شوند و مدل‌ها همدیگر را نقد و امتیاز می‌دهند (امتیازها ذخیره می‌شوند).
5. **داور** بهترین‌ها را ترکیب می‌کند و **بازبین** نهایی مطمئن می‌شود چیزی جا نمانده.
6. اگر یک سرویس بخوابد، **auto-fallback** خودکار می‌رود سراغ بعدی (`ChatResult.via` نشان می‌دهد از کجا آمده).

### اگر از ایران وصل می‌شوی

- **ساده‌ترین راه:** یکی از گیت‌وی‌های ایرانی را انتخاب کن — بدون VPN، پرداخت ریالی، یک کلید برای همه‌ی مدل‌ها. (پروکسی را خالی بگذار؛ لازم نیست.)
- **سرویس‌های خارجی (OpenAI/Gemini/Groq…):** در ⚙️ تنظیمات، پروکسی‌ات را بده — مثلاً `http://127.0.0.1:7890` یا `socks5://127.0.0.1:1080` (اگر کلاینتت SOCKS می‌دهد، پکیج سوکس از قبل نصب است) و «پروکسی برای» را روی `خارجی‌ها` بگذار تا ترافیک گیت‌وی ایرانی بی‌دلیل از پروکسی رد نشود. یا `MEGA_PROXY=...` را در `.env` بگذار.
- در آمریکا/اروپا برعکس است: گیت‌وی ایرانی از بیرون ایران بسته است (منتظر می‌ماند و تایم‌اوت می‌شود) → همان‌جا «بررسی همه‌ی سرویس‌ها» را بزن تا بهترین گزینه را خودش پیدا کند.
- پنل کاملاً فارسی و راست‌چین است و جواب‌ها هم فارسی‌اند.

**رابط وب حرفه‌ای (`/advanced`، فارسی، راست‌چین)** این تب‌ها را دارد:

| تب | کار |
|---|---|
| 🤖 **کارگزار مطلق** | خواسته‌ات را می‌نویسی؛ نقشه می‌چیند، ابزارها را واقعاً اجرا می‌کند، خطا را خودش دور می‌زند و فایل تحویل می‌دهد |
| 🧠 **پنل خبرگان** | چند مدل مستقل جواب می‌دهند → نقد متقابل → داوری و سنتز + جدول اعتماد که یاد می‌گیرد |
| 🎬 **استودیو** | ساخت تبلیغ ویدیویی، ویدیو از صحنه‌های دلخواه، پوستر/اسلاید (۹:۱۶، ۱۶:۹، ۱:۱) |
| 🎙 **صدا** | متن→گفتار (۶ صدا: فارسی/انگلیسی/عربی/ترکی) و گفتار→متن + ضبط صدا از میکروفون در مرورگر |
| 🧩 **مهارت‌ها** | نصب پکیج pip، افزودن فایل مهارت، نصب از مخزن git، به‌روزرسانی همه‌ی کتابخانه‌ها |
| 📨 **تلگرام** | فعال‌سازی دستیار تلگرام با یک توکن؛ هر پیام/صدا/فایل تو را کارگزار اجرا می‌کند |
| 🔑 **کلیدها** | کلیدهای API و تنظیمات اجرا (تعداد خبره، سقف گام کارگزار، ابزارها، بازبینی) |

## ۲) کارگزار مطلق — چه چیزهایی می‌تواند

**حلقه‌ی اجرا:** برنامه‌ریزی → اجرا → دیدن نتیجه‌ی واقعی → اصلاح → تحویل فایل

- 💻 **کد و پروژه:** نوشتن، اجرا، تست؛ ساخت پروژه‌ی FastAPI، سایت، PWA (اپ نصب‌شدنی موبایل)، ربات تلگرام، افزونه‌ی کروم، اسکلت فلاتر
- 📦 **سیستم:** `pip install`، `npm`، `git`، اجرای پس‌زمینه‌ی سرویس، ساخت با ffmpeg، دانلود فایل
- 🌐 **داده:** درخواست HTTP به هر API، جست‌وجوی وب، خواندن صفحات، استخراج داده، تحلیل با pandas، نمودار
- 🎬 **محتوا:** تبلیغ ویدیویی، ویدیو با زیرنویس، صداگذاری، پوستر — خروجی واقعی mp4/png/mp3
- 🔁 **خودترمیمی:** اگر خطا خورد راه دیگر امتحان می‌کند؛ نگهبان تکرار جلوی حلقه‌های بی‌فایده را می‌گیرد
- 📁 **تحویل:** همه‌ی فایل‌ها در `workspace/<نشست>/` با لینک دانلود (`/files/...`)

نمونه خواسته‌ها:

```
یک تبلیغ ۳۰ ثانیه‌ای برای فروشگاه لباس بساز، ۹:۱۶، با صداگذاری و موسیقی
یک سایت معرفی خدمات با فرم تماس بساز، اجرا کن و صفحه را تست بگیر
این داده را تحلیل کن، سه نمودار بده و یک خلاصه‌ی مدیریتی بنویس   ← فایل را بفرست
یک ربات تلگرام برای سفارش قهوه بنویس، تست کن و فایل zip بده
کتابخانه‌ها را به‌روز کن، بعد یک API با FastAPI بساز و روی پورت ۸۰۸۰ بالا بیاور
```

## ۳) دستیار صوتی و تلگرام

- **داخل وب:** دکمه‌ی 🎙 «گفتن» → صدایت به متن تبدیل و در کادر خواسته گذاشته می‌شود. متن→گفتار هم در تب صدا و هم به‌صورت API.
- **تلگرام:** تب 📨 تلگرام → توکن ربات (از [@BotFather](https://t.me/BotFather)) → «فعال کن». بعد:
  - هر پیام متنی → اجرای کامل و ارسال خروجی (ویدیو/تصویر/صدا/فایل)
  - 🎙 پیام صوتی → متن → اجرا
  - 📎 فایل/عکس → ذخیره و پردازش
  - `/say متن` → پاسخ صوتی، `/status`، `/new`
  - اجرای مستقیم از خط فرمان: `TELEGRAM_BOT_TOKEN=123:ABC python -m mega.telegram_bot`

## ۴) استودیوی محتوا (واقعاً فایل می‌سازد)

| قابلیت | جزئیات |
|---|---|
| تبلیغ ویدیویی | ۵ صحنه‌ی آماده: قلاب → مشکل → راه‌حل → اثبات → فراخوان، با صداگذاری و موسیقی |
| ویدیو دلخواه | هر صحنه: عنوان، متن گویندگی، نکات، تم؛ زیرنویس روی تصویر + فایل srt |

خروجی نمونه‌ها با همین سیستم ساخته شده‌اند: تصویر `poster` و ویدیوی `ad.mp4` (۱۰۸۰×۱۹۲۰، ~۲۵ ثانیه).

## ۵) کلیدها — با یک کلید هم کار می‌کند

| پرووایدر | مدل‌ها | لینک |
|---|---|---|
| **OpenRouter** ⭐ | GPT، Claude، Gemini، Grok، DeepSeek، Qwen، Llama، Mistral با یک کلید | openrouter.ai/keys |
| OpenAI | GPT-5 / 4.1 / 4o | platform.openai.com/api-keys |
| Anthropic | Claude Sonnet/Opus | console.anthropic.com |
| Google | Gemini 2.5 Pro/Flash | aistudio.google.com/apikey |
| xAI | Grok | console.x.ai |
| DeepSeek | V3 / R1 | platform.deepseek.com |
| Groq | Llama، Kimi | console.groq.com |

لیست مدل‌ها **از خود API** خوانده می‌شود. بدون هیچ کلیدی، سیستم یک **مدل نمایشی داخلی** بالا می‌آورد تا
کل خط تولید (کارگزار + ابزار واقعی + پنل + استودیو) را ببینی؛ با ثبت اولین کلید، خودکار کنار می‌رود.

کلیدهای اختیاری برای توان بیشتر: `TAVILY_API_KEY` (جست‌وجوی دقیق‌تر)، `TELEGRAM_BOT_TOKEN`، `OPENAI_API_KEY` (برای Whisper).

├── assets/fonts/          فونت وزیرمتن (برای رندر فارسی)

## ۹) تنظیم دقیق

در `.env` یا تب 🔑 کلیدها:

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `MEGA_AGENT_MAX_STEPS` | 24 | سقف گام‌های کارگزار (۰ = بی‌نهایت) |
| `MEGA_PANEL_SIZE` | 4 | تعداد خبره‌های موازی |
| `MEGA_USE_TOOLS` | true | ابزارهای اجرایی |
| `MEGA_VERIFY` | true | بازبینی نهایی |
| `MEGA_MODEL_TIER` | max | سطح قدرت: `max` (قوی‌ترین) / `balanced` / `cheap` |
| `MEGA_PROXY` | — | پروکسی برای سرویس‌های فیلترشده: `http://127.0.0.1:7890` یا `socks5://127.0.0.1:1080` |
| `MEGA_PROXY_SCOPE` | foreign | `foreign` = پروکسی فقط برای سرویس‌های خارجی، `all` = همه |
| `MEGA_AUTO_FALLBACK` | true | اگر یک سرویس خوابید، خودکار برود سراغ بعدی |
| `MEGA_KNOWLEDGE_BROADCAST` | true | کاوش موازی چند مدل و پخش دانش بین خبره‌ها |
| `MEGA_BROADCAST_SIZE` | 3 | چند مدل موازی کاوش کنند (۲ تا ۴) |
| `CUSTOM_BASE_URL` + `CUSTOM_MODELS` | — | سرویس سفارشی (گیت‌وی دیگر، Ollama، vLLM، LM Studio) |
| `OPENAI_BASE_URL` | — | همان کار، مخصوص OpenAI (مثلاً `http://localhost:11434/v1`) |

## ۱۰) در مورد «بی‌حد و مرز»

بدون سقف مصنوعی ساخته شده: هر ابزاری لازم باشد نصب می‌کند، هر کدی لازم باشد می‌نویسد و اجرا می‌کند،
هر فایلی لازم باشد می‌سازد، و محدودیت‌ها را از خودش درنمی‌آورد.
تنها مرزهای واقعیِ محیط اجرا اینهاست و شفاف اعلام می‌شود:

- کیفیت و توان مدل‌ها به **کلید API** تو بستگی دارد (بدون کلید = مدل نمایشی داخلی).
- اجرا داخل محیط سندباکس سرور است (نه روی کامپیوتر شخصی‌ات)، و برای کارهای نیازمند سخت‌افزار
  خاص (مثل build نهایی اپ موبایل با Android SDK) ابزارها باید نصب شوند — که سیستم خودش نصب می‌کند.
- هر کاری که از طریق API مدل انجام می‌شود، تابع سیاست همان سرویس‌دهنده است.
